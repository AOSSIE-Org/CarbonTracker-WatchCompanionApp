# CarbonTracker Brand Guidelines

## Logo

![CarbonTracker Logo](logo.svg)

The CarbonTracker logo is the primary visual identifier of the project.

## Colors

### Primary Colors

| Name                         | Hex       | Usage                                                             |
|------------------------------|-----------|-------------------------------------------------------------------|
| Primary                      | `#F7F5E8` | Primary accent / brand green, used for key actions and highlights |
| Main Background Color        | `#000000` | Main background color                                             |
| Focused elements and buttons | `#5E6F00` | Focus states, active elements, buttons                            |


## Typography

CarbonTracker uses default typography and does not currently use a custom font.

## Icons

CarbonTracker uses built-in Icons. No third-party icon library is currently used.

## Design Principles

- Clean and minimal
- Sustainability-focused
- Privacy-first
- Accessible and easy to read
